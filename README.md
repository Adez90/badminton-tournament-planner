# Badminton Tournament Planner

A tool to plan badminton club/regional tournament schedules: define your
classes (event type + skill level), courts, and average match lengths, and
get a conflict-free court schedule generated from your participant list.

- [`BLUEPRINT.md`](./BLUEPRINT.md) — domain model, the Swedish Badminton
  Federation rules it's grounded in, architecture decision, and roadmap.
- [`app/`](./app) — the React + TypeScript prototype. See
  [`app/README.md`](./app/README.md) to run it.
